# E-commerce
Exercicio para conclusão do curso vibe coding

Cenário de exercício

Você é um empreendedor que deseja usar um processo de codificação de vibração para criar um protótipo de aplicativo de compras. Seu protótipo inicial precisa demonstrar os recursos básicos que um usuário espera de um aplicativo de compras on-line e recursos específicos que você imaginou.

Você identifica as seguintes especificações de base para iniciar seu processo de desenvolvimento:

    Use HTML, CSS e JavaScript para criar um aplicativo da Web do lado do cliente.
    Inclua as seguintes páginas da Web: Produtos, Detalhes do Produto, ShoppingCart e Checkout.
    Ative a navegação entre as páginas.

Este exercício inclui as seguintes tarefas:

    Definir requisitos de produto : Use o GitHub Copilot para ajudar a fazer a transição de suas especificações de base para requisitos de produto mais detalhados.

    Crie um aplicativo protótipo inicial : Use o GitHub Copilot Agent e seus requisitos de produto para criar um aplicativo protótipo inicial.

    Refinar seu aplicativo protótipo : Use o GitHub Copilot Agent para concluir uma série de atualizações iterativas que refinam a experiência do usuário e garantem que seu aplicativo satisfaça os requisitos pretendidos.

## Como abrir o protótipo

Abra `VibeCoding-PrototypeApp/ShoppingApp/index.html` diretamente no navegador. Se preferir, inicie um servidor estático dentro da pasta `ShoppingApp` com `python3 -m http.server 8000` e acesse `http://localhost:8000`.
